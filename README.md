План обучения (от простого к сложному)
Вот roadmap, по которому мы будем двигаться. Я буду давать тебе микро-уроки по 1-2 темы за раз, чтобы ты мог усваивать в своем темпе.
Уровень 1: Основы protobuf (1-2 дня)
Синтаксис .proto файла (syntax, package, message)
Типы полей и номера (то, что мы уже обсудили)
Скалярные типы (int32, string, bool, float, и т.д.)
Поля repeated (массивы)
Поля optional и значения по умолчанию
Вложенные сообщения (message внутри message)
Enum (перечисления)
Oneof (когда только одно поле из нескольких может быть активно)
Map (словари ключ-значение)
Уровень 2: Работа с C++ (2-3 дня)
Генерация кода через protoc
Создание объектов, сеттеры/геттеры
Сериализация в бинарный файл
Десериализация из файла
Работа со строками и памятью
Arena для оптимизации аллокаций
Обработка ошибок
Уровень 3: CMake интеграция (1 день)
Настройка CMakeLists.txt для protobuf
Автоматическая генерация .pb.* файлов при сборке
Линковка библиотеки
Уровень 4: gRPC основы (2-3 дня)
Что такое gRPC и чем отличается от REST
Описание сервисов в .proto (service, rpc)
Генерация кода для gRPC
Реализация простого сервера
Реализация клиента
Unary вызовы (запрос-ответ)
Уровень 5: gRPC продвинутый (2-3 дня)
Server streaming (сервер отправляет поток данных)
Client streaming (клиент отправляет поток)
Bidirectional streaming (поток в обе стороны)
Обработка ошибок и таймауты
Метаданные (аналог HTTP-заголовков)
Уровень 6: Практика (1-2 дня)
Мини-проект: чат-сервер на gRPC
Мини-проект: API для управления списком гостей на дне рождения
